# hydro_practices

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/Hands-On-HydroAI-Education-Materials/hydro_practices/main?urlpath=lab)

위 링크는 hydro_practices 폴더 전체를 JupyterLab으로 엽니다.

- Binder는 링크를 열면 `binder/environment.yml`을 읽어 환경(CPU 전용 PyTorch 포함)을 자동으로 설치합니다. 처음 실행할 때 이미지를 빌드하므로 몇 분 걸릴 수 있습니다.
- Binder에는 GPU가 없습니다. 노트북은 GPU가 있으면 GPU를, 없으면 CPU를 사용합니다.
